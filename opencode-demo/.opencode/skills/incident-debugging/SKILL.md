# 故障诊断流程

发生回归、间歇性失败、无法解释的指标变化或生产类事故时，使用本 Skill。

## 基本原则

- 在修改任何内容之前先保留证据。
- 明确区分观察事实、假设和结论。
- 优先采用可逆、只读的诊断方式。
- 未经明确授权，不得重启服务、修改生产数据、变更基础设施或部署。
- 报告中不得暴露凭证或个人信息。

## 执行步骤

1. 复述症状、影响范围、开始时间和已知边界。
2. 建立证据表，记录来源、时间、观察结果和可信度。
3. 确认最后一个正常状态及之后发生的相关变更。
4. 给出不超过五个按可能性排序的假设。
5. 为每个假设设计成本最低、区分度最高的检查。
6. 一次运行一个已获授权的检查，并根据结果更新排序。
7. 只有证据充分时，才认定最可能的根因。
8. 分别给出止损、修复、验证和预防措施。

## 必须输出

- 故障摘要。
- 已收集证据。
- 假设排序及支持、反对证据。
- 最可能根因及置信度。
- 下一项安全操作。
- 验证计划。
- 尚未解决的问题。
